# slowpixel-school-day

SlowPixel module that shows:

- Weather at home
- Weather at school
- Next class(es) from your school calendar

Designed primarily for Czech students (SŠTŘ / IREDO region), but usable anywhere.

## Status

**Phase 1** – Dual weather + next classes (in progress)  
**Phase 2** – Leave-home time / simple transport (later)

See [SPEC.md](SPEC.md) for the full specification.

## Requirements

- SlowPixel device with **JavaScript modules enabled** (owner must turn this on in the dashboard)
- Google Calendar connected to the same SlowPixel account (the school timetable calendar)

## Installation (once the module is finished)

1. Enable JavaScript modules on your SlowPixel
2. Install from the catalog or paste the module code
3. Fill in the config fields (`home_place`, `school_place`, `calendar_id`, …)
