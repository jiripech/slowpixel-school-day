# Czech UI strings

All user-facing text is Czech and goes straight to the e-ink display — spell-check it. Known-correct spellings (from past review fixes):

- WMO 1 "mainly clear" → `převážně jasno` (NOT "prejímavě")
- WMO 48 rime fog → `mlha s námrazou` (NOT "mrholná mlha")
- WMO 56/57 → `mrznoucí mrholení` / `silné mrznoucí mrholení` (NOT "zmrazující")
- WMO 66/67 → `mrznoucí déšť` / `silný mrznoucí déšť`
- WMO 71/73/75 → `slabé sněžení` / `sněžení` / `silné sněžení` (NOT "sněh")
